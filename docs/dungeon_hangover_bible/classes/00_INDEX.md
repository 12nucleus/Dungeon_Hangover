## HOW CLASSES WORK

- There is **no class select screen**. You are Greg. You are in your underwear.
- At each **level-up**, you choose ONE skill from ANY of the 15 pools.
- Your "class" is what players call your build after the fact ("I accidentally built a fire-throwing coward").
- Skills have **level requirements** (character level, not class level).
- Skills cost **AP** (Action Points) to use. Most cost 1-3 AP. Passives cost 0.
- Skills can **stack** with other skills for combo effects. These are marked with [COMBO].
- **No pure support skills.** Every skill must benefit YOU directly.

## COMBO SYSTEM

Many skills have **[COMBO]** markings. These indicate skills that stack together for extra effects:

- **[COMBO: Skill Name + Skill Name]:** When both skills are active, an additional effect triggers.
- **Additive stacking:** Effects add together (e.g., +10% + +10% = +20%).
- **Multiplicative stacking:** Effects multiply (e.g., 1.5x * 1.5x = 2.25x).
- **Duration stacking:** Re-applying refreshes duration. Does not stack intensity unless noted.
- **One proc per turn:** Most proc-effects trigger once per turn unless noted.

See each class file for specific combo details.
